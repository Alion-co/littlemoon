# اندازه‌گیری سرعت (P4-4)

اعداد باید روی **گوشی واقعی** و حالت **profile** گرفته بشن (debug عدد درست نمی‌ده).
پیش از شروع، همه‌ی تغییرهای P4 رو یک‌بار با نسخه‌ی قبلی (commit قبل از P4-1) و یک‌بار با نسخه‌ی جدید اجرا کن و دو ستون عدد رو مقایسه کن.

## ۱) شمارش به‌روزرسانی providerها (ثبت آب / وزن / یادداشت)

```powershell
flutter run --profile --dart-define=PROVIDER_STATS=true
```

1. برنامه رو باز کن و صفحه‌ی اصلی رو ببین.
2. ۲۰ بار آب ثبت کن (دکمه‌ی آب)، بعد ۵ بار وزن و ۵ بار یادداشت.
3. ۱۰ ثانیه صبر کن؛ جدول `--- ProviderStats ---` توی کنسول چاپ می‌شه.

آنچه باید دید: `Provider<CycleSnapshot>` (موتور چرخه) و `Provider<List<PersonalPattern>>`
با این ثبت‌ها **بالا نره** (قبل از P4-1 با هر ثبت یک‌بار بالا می‌رفت).
فقط ثبت روز پریود، دما یا عوض کردن طول چرخه باید اون رو بالا ببره.

## ۲) تعداد rebuild ویجت‌ها

DevTools ← Flutter Inspector ← **Track widget rebuilds** (روی debug هم قابل استفاده‌ست؛ فقط برای شمارش، نه زمان).
همون سناریوی بالا: تعداد rebuild صفحه‌ی اصلی، سلامت و تقویم رو یادداشت کن.

## ۳) زمان فریم

DevTools ← **Performance** ← با برنامه روی صفحه‌ی اصلی (حلقه‌ی چرخه در حال «نفس کشیدن») ۳۰ ثانیه ضبط کن:

| معیار | قبل | بعد |
|---|---|---|
| میانگین زمان فریم UI (ms) | | |
| میانگین زمان فریم Raster (ms) | | |
| فریم‌های janky (٪) | | |
| تعداد نوشتن روی دیسک برای ۲۰ بار ثبت آب | | |

انتظار: بعد از P4-3 زمان Raster در صفحه‌ی اصلی کمتر بشه (حلقه دیگه با هر فریم
دوباره رسم نمی‌شه، فقط لایه‌اش بزرگ و کوچک می‌شه).

## ۴) نوشتن روی دیسک (P4-2)

ثبت‌های روزانه حدود ۶۰۰ میلی‌ثانیه بعد از آخرین تغییر نوشته می‌شن، یا همون لحظه که
برنامه به پس‌زمینه می‌ره / بازیابی پشتیبان / حذف داده‌ها انجام بشه. برای چک:
۲۰ بار آب ثبت کن و فوراً برنامه رو ببند؛ بعد دوباره باز کن، مقدار باید ثبت شده باشه.

# حجم و حافظه‌ی asset (فاز ۶)

## ۱) یک‌بار آماده‌سازی فایل‌ها

```powershell
powershell -ExecutionPolicy Bypass -File tool\prepare_assets.ps1 -DryRun   # فقط گزارش
powershell -ExecutionPolicy Bypass -File tool\prepare_assets.ps1
```

نسخه‌ی ۱۰۲۴ آیکون و لایه‌ی foreground به `design/` می‌رن (وارد APK نمی‌شن)، نسخه‌ی
۲۵۶ لوگو و ۱۲۸ نشان سازنده جاشون می‌شینن و دو فایل بی‌مصرف حذف می‌شن.
بدون ویندوز: با ImageMagick
`magick design/littlemoon_icon_full.png -resize 256x256 assets/images/logo/littlemoon_icon_full.png`
و همین‌طور `alion_badge` با `128x128`.
